# AI 사용 기록 집계 기준

이 카드는 현재 PC에 보관된 Claude Code·Codex JSONL 로그의 숫자 필드만 집계한 수동 갱신 스냅샷입니다. 전체 계정·다른 PC·삭제된 기록·웹 채팅 사용량을 대표하지 않습니다. 로그에 숫자가 없는 날짜의 빈 칸은 사용하지 않았다는 증거가 아닙니다.

- Claude Code: `message.id`와 `requestId`가 같은 스트리밍 응답·복제 기록은 한 번만 집계하고, 각 토큰 필드의 최댓값을 사용합니다. 입력·캐시 생성·캐시 읽기·출력을 합산합니다. `iterations`는 재합산하지 않습니다.
- Codex: 세션별 `total_token_usage`의 증가분을 집계합니다. 반복 이벤트는 제외하며, 복제된 동일 시각·누적 값 이벤트도 한 번만 집계합니다. 누적 값 감소는 카운터 초기화로 취급합니다. `cached_input_tokens`는 `input_tokens`에 포함되므로 중복 합산하지 않습니다. 추론 출력도 출력에 재합산하지 않습니다.
- 캐시 읽기 비율: 캐시 읽기 / (일반 입력 + 캐시 생성 + 캐시 읽기). 전체 입력 토큰 중 재사용된 토큰의 비율이며, 요청 단위 캐시 적중률과 다릅니다.
- 달력: `Asia/Seoul` 기준 일별 토큰, 현재 주 포함 최근 26주. 일요일 시작. 해당 기간 최대 일별 토큰 대비 0 / 10% 이하 / 30% 이하 / 60% 이하 / 60% 초과로 표시합니다.
- 공개 데이터: 소스별·모델별 토큰 합계, 일별 토큰, 단가·환율·환산액·제외 범위, 날짜·파싱 진단을 포함합니다. 프롬프트·응답·프로젝트 경로·세션 ID·자격증명은 포함하지 않습니다.
- 비용: 모델별 입력·5분/1시간 캐시 생성·캐시 읽기·출력 및 Codex 장문 할증을 구분해 공개 Standard·global API 단가로 환산합니다. 실제 청구액·구독료가 아닙니다. 공개 단가가 없거나 기록 검증에 실패한 부분은 금액에서 제외합니다. [모델별 금액·공식 출처·환율·제외 범위](./AI_USAGE_COST.md)를 확인하세요.
- 갱신: Python 표준 라이브러리만 사용합니다. 저장소 루트에서 `python scripts/generate_ai_usage.py` 실행 후 결과를 검토하고 직접 커밋합니다. 스크립트는 네트워크 접근·자동 업로드·원본 로그 변경을 하지 않습니다. GitHub Actions만으로 로컬 로그를 읽을 수는 없습니다.

원본 로그는 수정하지 않습니다. 카드 디자인은 이 프로필의 기존 색상·글꼴을 따르며, 다른 프로필의 SVG 코드를 복사하지 않았습니다.
